# TAES Common Evaluation Ontology: 04_Recommendation Model

The **Recommendation** model represents actionable guidance generated by expert agents to advise the startup on improvement paths. These recommendations are specific to each expert domain (e.g. TRL, IP, Finance) and target identified weaknesses and risks.

---

## 1. Schema Definition

Every Recommendation record must conform to the following schema:

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `recommendation_id` | `UUID` / `String` | Unique identifier (e.g. `REC-FIN-109`) |
| `priority` | `Enum` | Priority ranking: `High`, `Medium`, `Low` |
| `expected_outcome` | `String` | Qualitative description of the expected improvement and outcome |
| `affected_dimension` | `String` | The specific startup evaluation metric/dimension targeted |
| `estimated_score_improvement`| `Float` / `Null` | Projected score increase in the target metric (for future Score Engine use only) |
| `estimated_time` | `String` | Expected time frame to implement (e.g., `'1 month'`, `'2 weeks'`) |
| `estimated_cost` | `String` | Expected cost range to implement (e.g., `'Zero'`, `'INR 1,00,000'`) |
| `prerequisites` | `List[String]` | Specific milestones that must be achieved before starting |
| `dependencies` | `List[String]` | IDs of other recommendations this relies on |
| `difficulty` | `Enum` | Implementation complexity: `Easy`, `Medium`, `Hard` |
| `risk_reduction` | `String` | Description of which identified risks will be mitigated |
| `confidence` | `Float` | The reasoning confidence score (0.0 to 1.0) of the agent proposing this |
| `evidence` | `List[UUID]` | Evidence references backing the need for this recommendation |

---

## 2. Priority Levels

* **High**: Crucial recommendations that address Critical risks or make the startup immediately investable/grant-ready (e.g., filing a patent for core technology, extending runway beyond 3 months).
* **Medium**: Important optimizations that improve execution efficiency or product-market fit (e.g., conducting customer feedback cycles).
* **Low**: General advisory suggestions.

---

## 3. Serialization Example (JSON)

```json
{
  "recommendation_id": "REC-FIN-109",
  "priority": "High",
  "expected_outcome": "Extend cash runway from 2 months to 6 months by reducing monthly burn rate and obtaining bridge funding.",
  "affected_dimension": "cash_runway",
  "estimated_score_improvement": null,
  "estimated_time": "1 month",
  "estimated_cost": "Zero",
  "prerequisites": ["Analyze monthly recurring costs"],
  "dependencies": [],
  "difficulty": "Medium",
  "risk_reduction": "Mitigates RISK-FIN-02 (Existential threat of cashout within 60 days)",
  "confidence": 0.94,
  "evidence": ["EVID-XLS-102"]
}
```
