# TAES Common Evaluation Ontology: 07_Committee Ontology

The **Committee Ontology** provides a shared vocabulary, state lifecycle, and mapping schema to coordinate the Consensus and Committee Engines. It ensures all agents use identical terminologies, preventing semantic mismatches.

---

## 1. Unified Vocabulary & Domain Terms

* **Digital Twin (Startup Intelligence Profile)**: The complete, structured representation of all preferred claims and evidence belonging to a single startup.
* **Domain Assessment**: The structured `AgentAssessment` payload returned by a single expert agent.
* **Observation**: A single fact-evidence-reasoning unit.
* **Risk Pool**: The combined collection of Critical, Medium, and Low risks across all 9 domain expert assessments.
* **Founder Questionnaire**: The consolidated, deduplicated set of questions generated by the agents to resolve missing information.
* **Incubation Verdict**: The final incubation decision resolved by the committee.

---

## 2. Evaluation State Flows

A startup evaluation progress state is tracked using the following flow:

```
[DRAFT] ──► [READY_FOR_AGENTS] ──► [AGENTS_EVALUATING] ──► [CONSENSUS_COMPILING] ──► [COMMITTEE_REVIEW] ──► [VERDICT_RENDERED]
```

* **DRAFT**: Startup profile is incomplete, or claims are still in unvalidated/pending states.
* **READY_FOR_AGENTS**: Claims are validated and preferred. Context is ready for expert agents.
* **AGENTS_EVALUATING**: Domain agents are running AI Gateway completions.
* **CONSENSUS_COMPILING**: Consensus Engine is aggregating observations and checking for conflicts.
* **COMMITTEE_REVIEW**: The Committee Engine has generated the draft scorecard and consensus summary. Waiting for human approval or founder answers.
* **VERDICT_RENDERED**: Final score is calculated, consensus decision is made, and report is locked.
