# TAES Common Evaluation Ontology: 06_Confidence Model

To prevent arbitrary ratings, the TIDES AI Evaluation System (TAES) replaces simple confidence scores with a multi-layered **Confidence Hierarchy**. This guarantees that all uncertainties (source reliability, logic paths, and expert agreement) are modeled mathematically.

---

## 1. The Confidence Hierarchy

```
                    Final Confidence
                           ▲
                           │
                 Consensus Confidence
                           ▲
                           │
                  Domain Confidence
                           ▲
                           │
                Observation Confidence
                           ▲
         ┌─────────────────┼─────────────────┐
         │                 │                 │
Extraction Conf.    Evidence Conf.    Reasoning Conf.
```

---

## 2. Definitions & Conceptual Calculations

### 1. Extraction Confidence ($C_{ext}$)
* **Definition**: The raw score (0.0 to 1.0) assigned by the LLM during the initial extraction phase, indicating how clearly a claim was stated in a text chunk.
* **Calculation**: Generated directly by LLM prompt schemas based on linguistic matching.

### 2. Evidence Confidence ($C_{evid}$)
* **Definition**: A measure of the trustworthiness of the source material.
* **Calculation**:
  $$C_{evid} = W_{doc} \times M_{len}$$
  * $W_{doc}$: Base document type weight (e.g. Financial Statement = 0.95, Pitch Deck = 0.80).
  * $M_{len}$: Length multiplier of the supporting snippet (longer exact snippets represent better evidence quality, ranging from 0.8 to 1.0. Missing snippet = 0.5).

### 3. Reasoning Confidence ($C_{reas}$)
* **Definition**: Measures the logical distance between the raw evidence and the agent's deduction.
* **Calculation**: Direct matches (e.g. "GST certificate confirms revenue") get a high value (0.95). Inferences requiring multi-step logical deduction get a lower value (e.g. 0.60).

### 4. Observation Confidence ($C_{obs}$)
* **Definition**: The composite confidence of a single structured observation.
* **Calculation**:
  $$C_{obs} = (C_{ext} \times 0.4) + (C_{evid} \times 0.4) + (C_{reas} \times 0.2)$$

### 5. Domain Confidence ($C_{dom}$)
* **Definition**: The aggregated certainty of all observations within a specific expert agent's domain.
* **Calculation**: The weighted average of $C_{obs}$ for all preferred observations in the domain, adjusted by a **recency decay factor**:
  $$C_{dom} = \text{Average}(C_{obs}) \times d_{recency}$$
  * $d_{recency}$ decays the confidence if the key evidence is older than 6 months.

### 6. Consensus Confidence ($C_{cons}$)
* **Definition**: Generated by the Consensus Engine, representing the alignment between different expert agents.
* **Calculation**:
  * High alignment (e.g. TRL and Product agents agree) increases confidence ($+0.15$ agreement bonus).
  * Contradictions (e.g. Financial agent reports positive runway but Risk agent reports high burn rate) reduce confidence.

### 7. Final Confidence ($C_{final}$)
* **Definition**: The global confidence rating of the final evaluation report.
* **Calculation**: The composite of all domain and consensus confidences:
  $$C_{final} = \text{Average}(C_{dom}) \times C_{cons}$$
