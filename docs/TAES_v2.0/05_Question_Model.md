# TAES Common Evaluation Ontology: 05_Question Model

The **Question** model represents targeted inquiries generated by expert agents when critical information is missing from the Startup Intelligence Profile. These questions are aggregated by the future Committee Engine to produce a founder questionnaire.

---

## 1. Schema Definition

Every Question record must conform to the following schema:

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `question_id` | `UUID` / `String` | Unique identifier (e.g. `QST-FIN-104`) |
| `question` | `String` | The actual text of the question asked to the founder |
| `purpose` | `String` | The analytical reason why this question is being asked |
| `expected_evidence` | `String` | The specific document or validation proof requested as an answer |
| `affected_domain` | `String` | The evaluating agent domain (e.g. `'Founder'`, `'TRL'`, `'Market'`) |
| `priority` | `Enum` | Priority level: `High`, `Medium`, `Low` |
| `blocking_or_non_blocking` | `Enum` | If `Blocking`, incubation or funding cannot proceed without an answer |
| `generated_by_agent` | `String` | The domain key of the generating agent (e.g. `'financial'`) |

---

## 2. Examples by Domain

### TRL Agent:
* **Question**: "What environmental tests have been completed to validate prototype durability?"
* **Purpose**: Verify hardware robustness in field conditions.
* **Expected Evidence**: Outdoor testing log or third-party test certificate.
* **Blocking**: Blocking.

### Founder Agent:
* **Question**: "Has the founder previously managed a team larger than 20 people?"
* **Purpose**: Evaluate capability to scale operations.
* **Expected Evidence**: Founder text response or past company reference.
* **Blocking**: Non-Blocking.

### Financial Agent:
* **Question**: "Why is the Customer Acquisition Cost (CAC) missing from the financial summary?"
* **Purpose**: Evaluate marketing efficiency and unit economics.
* **Expected Evidence**: Sales ledger or marketing audit document.
* **Blocking**: Blocking.

---

## 3. Serialization Example (JSON)

```json
{
  "question_id": "QST-FIN-104",
  "question": "How was the projected Customer Acquisition Cost (CAC) of INR 1,500 calculated?",
  "purpose": "To verify unit economics scalability and marketing efficiency assumptions.",

  "affected_domain": "Financial",
  "priority": "High",
  "blocking_or_non_blocking": "Blocking",
  "generated_by_agent": "financial"
}
```
